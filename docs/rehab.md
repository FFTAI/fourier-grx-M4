# 康复使用

本栏目面向康复治疗师、临床带教老师和现场治疗团队，使用治疗师能理解的语言说明 M4L 的准备、训练模式选择、参数调节、过程监控和停止标准。

> ⚠️ **重要说明**
>
> 本栏目是设备使用说明，不构成诊断、处方或治疗建议。患者是否适用、训练强度、禁忌证和停止标准，应由具备资质的医生 / 治疗师结合患者情况、产品说明书和所在机构规范决定。

## 从哪里开始

- [治疗师使用指南](/fourier-grx-M4/docs/rehab/therapist_guide)：从患者评估到训练记录的完整流程。
- [关节零位校准](/fourier-grx-M4/docs/usage/calibrate)：M4L 上电后的校准顺序。
- [M4L 机器人](/fourier-grx-M4/docs/quickstart/m4l)：开机、登录和启动控制程序。
- [任务描述](/fourier-grx-M4/docs/tasks)：需要核对 TID、参数或保护行为时查阅。

## 治疗师与工程师的分工

| 角色 | 主要关注 | 不应独自决定 |
|------|----------|--------------|
| 治疗师 | 患者评估、训练目标、模式与强度、过程监护、停止训练 | 修改底层控制参数、绕过保护、直接发关节指令 |
| 现场工程师 | 设备连接、校准、固件版本、网络、日志、故障处理 | 替代治疗师做临床判断 |
| 开发者 | User / Developer API、任务扩展、数据分析 | 在未验证的情况下直接用于患者 |

建议在机构内明确“谁可以改哪些参数、谁可以急停、谁可以结束训练”，并把急停和停止训练的操作写入现场流程。
