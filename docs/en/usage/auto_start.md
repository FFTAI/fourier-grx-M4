# Auto-Start on Boot

```bash
fourier-grx enable_service   # Enable auto-start on boot
fourier-grx disable_service  # Disable auto-start on boot
```

> ℹ️ If the robot is configured for gamepad control mode, after enabling auto-start make sure the gamepad is connected and awake before powering on.
