# Installation Issues

## Installation Interrupted

**Symptom**: The installer exits due to an accident or misoperation.

**Solution**: Simply re-run the installer. Any previously installed content will be cleaned up automatically.

## Robot Model Configuration Failure

**Symptom**: During installation, the installer prompts you to enter a number to configure the robot model, but reports a configuration error and exits after input.

**Solution**:

1. Confirm you entered the **numeric ID**, not the option name as text
2. Restart the installer and reconfigure
