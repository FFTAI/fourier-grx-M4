# 治疗师使用指南

* TOC
{:toc}

本指南把 `fourier-grx` 的任务、参数和状态字段翻译成治疗流程中的语言，帮助治疗师完成一次安全的 M4L 训练。它不替代医生 / 治疗师评估、产品说明书和机构安全规范。

> ⚠️ **使用边界**
>
> - 机器人是训练设备，不是诊断设备；
> - 页面中的任务和参数只说明“设备能做什么”，不构成处方；
> - 患者是否适用、训练强度、禁忌证和停止标准，必须由有资质的临床人员判断；
> - 任何时候，硬件急停和受过训练的人员在场，优先于软件操作。

## 1. 一次治疗的完整流程

```text
患者评估
  → 知情同意 / 禁忌筛查
  → 穿戴与支撑
  → 设备开机、自检、校准
  → 选择训练模式与参数
  → 空载 / 短时试运行
  → 正式训练
  → 过程监护
  → 停止、站立、解除支撑
  → 记录与交接
```

建议把这条流程打印在治疗区，并在每一步写明“谁确认、在哪里记录”。

## 2. 治疗前检查

### 患者

- 由医生 / 治疗师完成适应证、禁忌证和风险评估；
- 确认患者当前状态适合站立和步行训练；
- 确认已获得知情同意；
- 询问疼痛、痉挛、疲劳、头晕、畏寒或其他不适；
- 确认皮肤完整，必要时使用衬垫；
- 确认患者理解“如何示意停止”和“治疗师会随时停止”。

### 环境与人员

- 治疗区地面防滑、无障碍物；
- 机器人周围留有治疗师可操作和支撑的空间；
- 急停按钮可及，且治疗师知道硬件急停与软件停止的区别；
- 至少一名受过训练的人员全程在患者身边；
- 不建议在无人看护或患者独自使用的情况下进行站立 / 行走训练。

### 设备

- 设备已开机，执行器指示灯正常；
- 手柄或上位机连接正常；
- 电池电量足够完成本次训练；
- 绑带、护具、足托和支撑结构完好；
- 机器人已完成本次上电后的校准。

## 3. 设备准备

### 3.1 校准

M4L 上电后必须按顺序完成：

| 顺序 | 任务 | TID | 目的 |
|------|------|-----|------|
| 1 | 直线关节自动校准 | 4210 | 腿长机构缩至最短并归零 |
| 2 | 旋转关节自动校准 | 4120 | 髋 / 膝边界检测并写入零点 |

详细步骤、插销管理和安全距离见[关节零位校准](/fourier-grx-M4/docs/usage/calibrate)。

> 校准前确认患者不在机器人运动范围内。自动校准过程中不要触碰机械腿。

### 3.2 腿长与穿戴

- 根据患者身高和下肢长度设置腿长；
- 左右腿长度、绑带松紧和足托位置要对称；
- 确认膝关节、髋关节和躯干绑带没有压迫或滑脱；
- 患者双脚稳定承重后再进入站立 / 行走任务；
- 需要调节腿长时，按现场上位机或任务页说明操作。

### 3.3 膝关节限制

伸膝限制用于限制参考轨迹中的膝关节伸展角度，不是独立的机械限位。

- 设置前先确认患者实际膝关节活动范围；
- 不要用提高刚度把患者“压”向受限角度；
- 左右腿限制不同时，当前实现会取较大的受限需求，实际行为应按较大限制理解；
- 训练开始后观察实际膝角、代偿和患者反应，而不是只看界面数字。

## 4. 训练模式怎么选

| 治疗目标 | 可考虑的任务族 | 典型任务 | 主要作用 |
|----------|----------------|----------|----------|
| 早期被动引导 | 被动行走 / 踏步 | 4129 / 4130 | 由设备按预生成轨迹带动 |
| 预生成步态、参数档位化 | 谐波系数被动前向行走 | 4131 | 幅度、伸膝限制、步频档位 |
| 主动参与、需要改变关节刚度 | 助力 PD | 4116 / 4117，谐波版 4132 | 助力系数改变 PD 增益 |
| 主动参与、需要改变节奏 | 助力 DT | 4118 / 4119，谐波版 4133 | 助力系数改变轨迹播放速度 |
| 伸膝受限患者 | 膝限任务 | 4301–4306 | 在参考轨迹层限制膝伸展 |
| 训练前预览轨迹 | 规划器 | 4401–4409 | 只计算和上报，不驱动关节 |

> ⚠️ 具体任务选择必须结合患者情况和机构方案。规划器只用于预览，不应作为训练输出。

### PD 与 DT 的区别

- **PD 助力**：助力系数改变关节对参考轨迹的跟随强度。系数低时关节更柔顺，患者可偏离参考；系数高时更接近被动引导。
- **DT 助力**：助力系数改变轨迹播放速度。系数低时动作更慢，给患者更多反应时间；系数高时节奏更快。
- 两者都不是“助力力矩百分比”，也不是“患者主动用力百分比”。

## 5. 参数的治疗师解释

| 界面 / 字段 | 治疗师可以怎么理解 | 不要误解为 |
|-------------|--------------------|------------|
| 助力系数（PD） | 关节跟随参考轨迹的强弱 / 柔顺程度 | 机器人承担了多少百分比的力 |
| 助力系数（DT） | 轨迹播放快慢 | 直接增加力矩 |
| 步长 / 步频 / 步高 | 步态幅度、节奏和抬脚高度 | 患者肌力指标 |
| 伸膝限制 | 参考轨迹的膝伸展下限 | 机械硬限位 |
| 过载保护 | 允许的最大关节负载上限 | 训练强度目标 |
| `assist_ratio` | 当前实际生效的助力系数 | 患者主动参与度 |
| `active_ratio` | **预留字段，当前固定为 0** | 患者主动用力占比 |

`active_ratio` 目前不能用于患者主动参与度评估；`assist_ratio` 也不能直接当成患者努力程度。判断患者参与情况，应结合治疗师观察、患者主诉、动作质量和疲劳程度。

## 6. 训练中的监护

### 建议持续观察

- 患者表情、呼吸、疼痛、痉挛和疲劳；
- 躯干控制、足跟着地、膝关节方向和代偿动作；
- 绑带是否松动、足托是否移位；
- 机器人是否有异常声音、抖动、加速或停顿；
- 上位机 / 终端是否出现错误、保护或断连提示。

### 软件里可以看什么

| 数据 | 用途 | 注意事项 |
|------|------|----------|
| `rehab.assist_ratio` | 当前助力系数 | 不是患者努力程度 |
| `rehab.motion_ratio` | 当前动作完成比例 | 不是训练效果 |
| `rehab.step_frequency` | 当前步频 | 用于核对节奏 |
| `rehab.reference_joint_position` | 参考关节位置 | 不是实测关节位置 |
| `rehab.reference_joint_position_*` | 参考轨迹包络 | 用于预览活动范围 |
| `grx.robot_error_codes` | 错误码 | 出现错误时先停止训练 |
| `flag_robot_*_protection` | 保护标志 | 锁存，需要按流程清除 |

### 停止训练的情况

出现以下任一情况，应立即停止训练并保护患者：

- 疼痛、明显痉挛、异常抵抗或患者要求停止；
- 头晕、面色改变、呼吸异常或明显疲劳；
- 机器人异常加速、抖动、异响、卡顿；
- 关节接近机械限位或出现异常代偿；
- 绑带滑脱、足托移位、患者支撑不稳；
- 上位机报错、断连、保护触发或急停；
- 治疗师对安全性有任何不确定。

停止后先保持支撑，再按流程切换到站立 / 失能，确认患者稳定后再处理报警。

## 7. 训练记录

一次训练建议记录：

- 患者 ID、日期、训练时长；
- 机型、固件版本、上位机版本；
- 任务名称 / TID、训练模式（被动 / PD 助力 / DT 助力）；
- 助力系数、步长、步频、步高、伸膝限制、过载保护；
- 实际训练时长、步数 / 步频、异常事件；
- 患者主观感受、疼痛 / 疲劳评分；
- 停止原因和处理结果。

上位机的训练报告可以导出 PDF / Excel；导出前核对患者、日期和参数是否与实际训练一致。

## 8. 常见问题

### 患者觉得“没有助力”

先确认当前是 PD 还是 DT 模式：

- PD 模式改变的是关节刚度，低助力系数仍然可能有基础 PD 力矩；
- DT 模式改变的是播放速度，不是力矩大小；
- 检查助力系数是否实际下发，以及任务是否在参数生效后才启动。

### 患者觉得“太快”

- DT 模式优先降低助力系数，让轨迹播放变慢；
- 检查步频档位是否过高；
- 不要只靠提高刚度来“稳住”患者，刚度提高可能增加交互力。

### 膝关节不舒服

- 先停止训练，检查伸膝限制、腿长、绑带和足托；
- 观察实际膝角与参考轨迹的差异；
- 不要用提高助力系数掩盖疼痛或代偿。

### 界面显示 ERR 或没有角度

- 确认任务已进入并已收到 `rehab` 数据；
- 检查固件版本是否支持 `reference_joint_position_max/min`；
- 记录错误信息并联系现场工程师，不要用本地估算值替代设备数据。

## 9. 对上位机界面的建议

如果治疗师是主要使用者，建议在上位机中提供“治疗师模式”：

- 隐藏 TID、原始字段名和底层参数；
- 使用“被动行走 / 助力行走 / 原地踏步 / 伸膝限制”等治疗语言；
- 提供患者档案、常用参数预设和本次训练摘要；
- 把助力、步频、步长、伸膝限制放在同一页；
- 保留醒目的“停止训练”和“急停”；
- 训练结束后自动生成本次记录，而不是让治疗师手工抄字段。
