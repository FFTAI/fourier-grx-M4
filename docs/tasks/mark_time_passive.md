# 被动原地踏步

* TOC
{:toc}

## 任务信息

| 任务 | 任务值 (TID) | 控制方式 |
|---|---|---|
| 被动原地踏步 | **4130** | PD |
| 被动原地踏步 + 速度前馈 | **4112** | PD + 速度前馈 |
| 被动原地踏步 · POSITION + 速度前馈 | **4126** | POSITION + 速度前馈 |

> POSITION + 速度前馈变体走执行器位置环，参数与 PD 变体相同。

任务描述：

- 机器人通过给定参数，生成原地踏步的关节运动轨迹序列，通过执行器跟踪该轨迹，实现被动原地踏步。
- 发送"停止运动标志位"为 true 时，机器人将逐渐停止运动，并不是立即停止。
- 触发力矩保护后，机器人立即退出本任务并切换至空闲任务（`TASK_IDLE`），同时置位过力矩保护标志，需重新下发本任务才能继续踏步。
- 4112 与 4130 共用轨迹与面板参数，仅在执行阶段叠加参考速度前馈；P1/T1 的 FSA v2 协议没有 velocity 字段，PD 前馈仅在 M4LT2 生效。

任务参数：

| 接口参数     | 类型      | 默认值   | 参数范围          | 描述                                         |
|----------|---------|-------|---------------|--------------------------------------------|
| 大腿长度     | `float` | 0.5   | [0.3, 0.6]    | 机器人的大腿长度，单位为 m。                            |
| 小腿长度     | `float` | 0.5   | [0.3, 0.6]    | 机器人的小腿长度，单位为 m。                            |
| 抬腿高度     | `float` | 0.1   | [0.1, 0.4]    | 机器人每一步的抬腿高度，单位为 m。                          |

| 基座高度     | `float` | None  | [0.6, 1.2]    | 踏步时基座（骨盆）离地高度，单位为 m。≤ 0 或未发送时自动取大腿+小腿长度之和。超出范围会被限幅到该范围内。下次起步（轨迹重新生成）时生效，踏步过程中修改不影响当前正在执行的轨迹。 |

| 启用力矩保护开关 | `bool`  | false | (true, false) | 是否启用力矩保护功能                                 |

## 原理解释

### 算法运行原理

原地踏步采用 VHIP 的两连杆几何生成器，但把质心和支撑点固定在原地，核心是“**左右交替的足端周期运动 → 髋膝逆解 → 循环播放**”：

1. **建立步态时序**：输入步行周期直接作为 `T_step`，每个周期由一侧摆动、另一侧支撑，下一步交换左右角色；步频上报为 `60/T_step`（步/分钟）。与前向行走不同，这里不通过步长除以步速计算周期。
2. **构造足端轨迹**：支撑脚位置保持不变，质心水平位置和基座高度保持设定值。摆动脚垂直方向为 `z=h·(1−cos(2πτ))/2`，前后方向为 `x=L_max·sin(πτ)`，其中 `L_max=min(2h,L_thigh)`。因此脚在周期末回到原水平位置，只产生抬腿和前后摆动，不形成持续前进位移。
3. **求关节参考**：逐帧计算足端相对质心的距离 `d`，通过余弦定理求膝角，结合 `atan2` 和余弦定理求髋角，再转换到 URDF 坐标。膝限在生成阶段执行，生成器本身不额外低通，以避免增加原地轨迹延迟；参考速度由位置差分获得。
4. **状态机执行**：启动前保持实测姿态，启动后先用 2.5 秒进入轨迹首帧，再循环读取左右两步序列。外层仍使用 `q_cmd[k]=(1−α)q_cmd[k−1]+αq_ref[k]` 平滑并限幅；停止标志在循环边界进入收尾，暂停则冻结当前输出。
5. **负载检测**：以 `P=τω` 的正功率累计步内能量，原地踏步阈值是 `70 J`；超过后 PD 逐渐向 hard 档爬升，以提高带载跟踪刚度。该能量包含设备和患者的共同机械功，不能直接作为患者主动做功。

### 康复临床使用建议

- 原地踏步可在不承担前进位移管理的情况下进行被动关节活动和步态节奏熟悉，但仍需悬吊或可靠支撑，不能假设“原地”就无需防跌倒保护。
- 初次宜采用较低抬腿高度和较长步行周期，确认髋膝活动范围、负重耐受及足部间隙后再逐步调整。抬腿目标应服从患者无痛活动范围，不用于强行牵伸。
- 建议启用力矩保护并观察实际左右对称性、疼痛、痉挛和疲劳。`motion_ratio` 与步频只描述任务运行，不代表患者主动参与度或功能性步行能力。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
