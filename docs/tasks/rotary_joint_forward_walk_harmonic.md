# 被动前向行走 谐波拟合

## 任务信息

| 任务 | 任务值 (TID) | 控制方式 |
|---|---|---|
| 被动前向行走 谐波拟合 | **4131** | PD |
| 被动前向行走 谐波拟合 + 速度前馈 | **4113** | PD + 速度前馈 |
| 被动前向行走 谐波拟合 · POSITION + 速度前馈 | **4127** | POSITION + 速度前馈 |

> POSITION + 速度前馈变体走执行器位置环，参数与 PD 变体相同。

适用机型：M4L（P1 / T1 / T2）

任务描述：

- 与[被动前向行走（4129）](/fourier-grx-M4/docs/tasks/forward_walk_passive)的区别只在**步态来源**：被动前向行走由 LIPM 倒立摆模型按步长/步速在线推导关节轨迹；本任务直接回放 Fourier-GRX 主表（预存的 Fourier 谐波系数）采样出的一条周期性关节曲线。
- 因此轨迹的**形状是固定的**，由"髋摆动幅度等级"与"伸膝限制等级"两条轴从 16 条曲线里选定；**节奏**由"步频等级"单独决定。三档互相独立。
- 本任务**只指令关节角度，不指令位移**：基座（骨盆）的前进量不由算法给出，实际走多远取决于使用者与外骨骼的整体运动，表中不承诺步长。
- 发送"停止运动标志位"为 true 时逐渐停止（走满当前循环窗后进入 1 s 收尾过渡），不会立即停止。
- 触发力矩保护后立即退出本任务并切换至空闲任务（`TASK_IDLE`），需重新下发本任务才能继续。
- 4113 与 4131 共用轨迹与面板参数，仅在执行阶段叠加参考速度前馈；P1/T1 的 FSA v2 协议没有 velocity 字段，PD 前馈仅在 M4LT2 生效。

> 关节角度范围与硬件行程的关系：髋最大约 −30°…+15°（行程 −90°…+40°），膝 0°…55°（行程 0°…110°），各档位均留有余量。

**参数生效时机**：面板参数每个控制周期都会被读取，但**整条轨迹只在任务进入后、按下"启动"之前生成一次**。因此：

- 启动前改档位 → 立即用于本次起步；
- 行走过程中改档位 → 不影响正在执行的轨迹，**下一次起步**（停止后重新启动任务）才生效；
- 步频等级改的也只是下一次起步的轨迹采样节奏。

## 原理解释

### 算法运行原理

本任务的核心是“**离线曲线拟合，在线按相位回放**”，与 DSP/VHIP 的实时几何求解不同：

1. **选择系数表**：髋幅度档与伸膝限制档组成 `4×4` 个步态键名。每个键名保存左右髋、膝各自的 Fourier 系数，曲线已预先转换到 URDF 弧度坐标；运行时不计算质心、足端或逆运动学。
2. **由谐波重建角度**：对每个关节使用 `q(φ)=a0+Σ[k=1..K](a_k·cos(2πkφ)+b_k·sin(2πkφ))`，其中相位 `φ∈[0,1)`，当前系数表 `K=10`。`a0` 决定平均姿态，低次项决定主要步态形状，高次项补充局部细节；左右腿的相位差已经包含在各自系数中。
3. **给曲线添加时间轴**：步频档先给出目标大步时间 `T_stride`，再按控制周期量化为整数帧 `N=round(T_stride/Δt)`，实际周期为 `N·Δt`。第 `n` 帧相位为 `φ=(n mod N)/N`，因此改变步频档只改变同一形状曲线的采样播放速度，步频上报为 `60/(N·Δt/2)`。
4. **拼接起停与循环**：站立参考姿态与循环第 0 帧之间用三次 Hermite 曲线连接，端点速度经过单调性限制以减小过冲；循环窗包含完整左右周期，回跳时相位连续。生成后按髋 `−90°…40°`、膝 `0°…110°` 限幅，并由最终位置差分得到参考速度。
5. **沿用通用执行状态机**：启动前保持实测位置，启动后先经 2.5 秒进入步态首帧，再进行起步、循环与收尾播放；外层仍有一阶位置平滑、输出限位、负载能量检测和 PD 爬升。患者交互力矩可以影响负载判定和跟踪误差，但不会在线改写 Fourier 系数或曲线形状。

### 康复临床使用建议

- 固定曲线适合需要重复一致引导的训练，但不能替代个体化步态评估。首次宜选择较低髋幅度和较慢步频，确认患者耐受后再单项调整，避免同时增加幅度和速度。
- 伸膝限制档应依据医生/治疗师测得的膝伸展活动范围选择，用于避免参考轨迹进入受限位置，不应用于强迫伸膝或治疗挛缩。
- 本任务只给定髋、膝参考角度，实际位移、步长和稳定性仍受患者与外部支撑影响。应启用力矩保护并监护实际步态，不能用档位或参考轨迹推断患者独立步行能力。
- 若固定曲线与患者活动范围、左右对称性或步态目标不匹配，应停止并改用更合适的任务，而不是通过外力强行使患者跟随。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
