## 原理解释

### 算法运行原理

TID 999 目前只有任务枚举占位，没有注册到 M4L 的可执行控制模型，因此不存在“接收指令后采样并写零”的运行链路，下发后不能完成任何关节校准。

从算法上看，M4L 的零点校准需要完成两件不同的事情：

- **建立坐标偏置**：读取编码器位置，将某一机械姿态映射为应用层 `0 rad` 或直线关节的参考位置，使后续 `q_application = f(q_encoder, home_offset, direction)` 在各任务间保持一致。
- **处理机型与关节差异**：旋转关节需要结合机械边界或人工零位进行位置采样，直线关节则通过全行程限位检测建立腿长坐标。两者的执行器方向、单位、持久化方式和重启要求都不同，不能由一个未实现的通用 TID 统一替代。

因此 M4L 必须分别调用旋转关节与直线关节专项任务；本页不能作为可运行的校准入口。

### 康复临床使用建议

- 不要在患者穿戴设备时尝试本占位任务，也不要把无运动或无报错理解为校准成功。应按患者下机后的维护流程选择对应专项校准任务。
- 零点决定后续轨迹在软件坐标中的实际姿态，错误的零点可能造成左右不对称或关节逼近不舒适位置；校准后须先空载核查，再进行治疗前准备。
- 临床人员不应通过任意设零来迁就患者畸形、挛缩或疼痛姿态；这类需求应由医生/治疗师与工程人员共同评估，并使用规定的膝限及适配参数。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
