> ⚠️ **该任务暂未实现。** TID 999 定义在通用机器人任务表 `TaskMenuGRX.TASK_SET_HOME` 中，`TaskMenuM4L`（4000–4999 段）没有对应实现。

## 原理解释

### 算法运行原理

TID 999 目前只有任务枚举占位，没有可执行的校准算法，下发后不能完成任何关节零点设置。零点校准的本质应是建立传感器读数与软件关节坐标之间的参考关系；M4L 需分别使用旋转关节和直线关节的专项任务完成这一过程。

### 康复临床使用建议

- 不要在患者穿戴设备时尝试本占位任务，也不要把无运动或无报错理解为校准成功。应按患者下机后的维护流程选择对应专项校准任务。
- 零点决定后续轨迹在软件坐标中的实际姿态，错误的零点可能造成左右不对称或关节逼近不舒适位置；校准后须先空载核查，再进行治疗前准备。
- 临床人员不应通过任意设零来迁就患者畸形、挛缩或疼痛姿态；这类需求应由医生/治疗师与工程人员共同评估，并使用规定的膝限及适配参数。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
