# 站立姿态控制

## 任务信息

任务值 (TID): **4020**

任务描述：

- 机器人缓慢移动各个关节恢复到站立姿态。
- 通常作为运动任务前的准备动作，或在运动结束后恢复初始姿态时使用。
- 支持力矩保护功能：当任意关节力矩持续超过设定阈值 0.1 s（v4.4.75 起）时，任务将立即退出并切换至空闲任务（`TASK_IDLE`），同时置位过力矩保护标志，需重新下发本任务才能继续。

任务参数：

| 接口参数     | 类型      | 默认值   | 参数范围         | 描述                                   |
|----------|---------|-------|--------------|--------------------------------------|
| 启用力矩保护开关 | `bool`  | false | (true, false) | 是否启用力矩保护功能。启用后，当任意关节力矩持续超过"保护力矩限值" 0.1 s（v4.4.75 起）时，任务将立即退出并切换至空闲任务（`TASK_IDLE`），同时置位过力矩保护标志，需重新下发本任务才能继续。                  |
| 保护力矩限值   | `float` | None  | [0.0, 200.0] | 站立过程中任意关节允许的最大输出力矩，单位为 Nm。仅在启用力矩保护时生效，默认不启用。         |

> **任务说明**：
>
> 任务激活后先在 0.2 秒预热阶段以纯阻尼（kp=0）稳定关节，再从当前关节位置出发，在约 5 秒内插值到站立目标姿态（四个旋转关节角度均为 0 rad），随后用「静止确认」判断机械真的停住（连续 0.2 秒内位置变化不超过 0.01 rad 且全部关节速度不超过 0.05 rad/s，最多额外等 2.5 秒后超时放行），再进入保持阶段。自 `fourier-grx` v4.4.76 起，静止确认完成前对外上报的 `motion_ratio` 封顶在 99.9%，任务完成标志同样顺延。之后保持站立不动，直到收到其他任务指令。

## 模块信息

该任务暂无独立模块指令，不支持通过模块接口进行分关节控制。

## 接口信息

状态接口：

| 接口参数   | 接口映射关系                  |
|--------|-------------------------|
| 任务启动标志 | `task.flag_task_start`  |
| 任务结束标志 | `task.flag_task_finish` |
| 运行比例   | `rehab.motion_ratio`    |

指令接口：

| 接口参数     | 接口映射关系                               |
|----------|--------------------------------------|
| 启用力矩保护开关 | `grx.virtual_panel_command_switch_1` |
| 保护力矩限值   | `grx.virtual_panel_command_param_9`  |

## 更新日志

- `fourier-grx` v3.1.1 版本新增该功能。
- `fourier-grx` v4.4.72 版本将本任务 PD 由基线档改为 medium 档：M4LP1 为 kp `[350×4]` / kd `[25×4]`，M4LT1 / M4LT2 为 kp `[500×4]` / kd `[30×4]`。0.2 秒纯阻尼预热不变，预热结束后恢复 medium 档。
- `fourier-grx` v4.4.74 版本：本任务触发力矩保护后置位的过力矩保护标志 `flag_robot_torque_protection` 改为**锁存**，不再随任务退出自动清除，需上位机写入 `clear_flag_robot_torque_protection` 清除。保护触发后的动作不变：仍立即退出本任务并切换至空闲任务（`TASK_IDLE`）。
- `fourier-grx` v4.4.75 版本：本任务的软件力矩保护增加 **0.1 s 消抖**——需连续超过「保护力矩限值」达 0.1 s（按控制周期折算：50 Hz 为 5 拍、100 Hz 为 10 拍、200 Hz 为 20 拍）才触发，任一拍回落到限值及以下即清零计数；触发后的动作与标志锁存行为不变。此前为零延时判定，瞬时力矩尖峰可能误退出任务。
- `fourier-grx` v4.4.76 版本：本任务的到位判定在插值时间之外增加**静止确认**——目标钉到站立场后，还需连续 0.2 s 满足「窗口内位置变化 ≤ 0.01 rad 且全部关节 |速度| ≤ 0.05 rad/s」才进入保持阶段，最长额外等待 2.5 s 后超时放行并打印告警。此前时间一到即切换，会把实测位置滞后目标的那部分动态误差对应的支撑力矩一并丢掉，表现为抽动。静止确认完成前 `motion_ratio` 封顶 99.9%，`flag_task_finish` 同步顺延；将 `flag_settle_check` 置 False 可退回纯时间判定。
