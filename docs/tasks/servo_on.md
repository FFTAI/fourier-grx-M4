# 执行器使能

* TOC
{:toc}

## 任务信息

任务值 (TID)： **35**

任务描述：

- 将所有执行器使能，电机启动输出力矩。

任务参数：

该任务无可配置参数。

## 模块信息

该任务暂无独立模块指令，不支持通过模块接口进行分关节控制。

## 接口信息

状态接口：

| 接口参数   | 接口映射关系                  | 说明                |
|--------|-------------------------|-------------------|
| 任务启动标志 | `task.flag_task_start`  | 使能过程中为 SET        |
| 任务结束标志 | `task.flag_task_finish` | 所有执行器使能完成后置为 SET  |

指令接口：

该任务无需额外指令参数，发送 TID=35 即可触发。

## 原理解释

### 算法运行原理

本任务的本质是一个**执行器控制模式状态机**，不包含轨迹生成或闭环姿态控制：

1. **下发使能**：进入 `STAGE_INIT` 后，工作空间切到 `ACTUATOR_SPACE`，向全部执行器写入 `SERVO_ON`，同时将位置、速度、力矩和电流目标清零，避免使能命令与旧的运动目标叠加。
2. **结束瞬态命令**：后续 `STAGE_START` / `STAGE_RUN` 将控制模式恢复为 `NONE`，使能状态由执行器保持；任务层不再根据关节误差计算新的输出。
3. **退出任务**：流程进入 `STAGE_FINISH` 后切换到 `TASK_IDLE`，等待站立或步态等后续任务提供真正的位置目标和 PD 参数。

因此，“使能完成”表示这条控制模式流程已经执行，不代表机器人已达到某个姿态，也不代表患者负重状态已经稳定。

### 康复临床使用建议

- 本任务属于治疗前准备或治疗后恢复步骤，不是独立康复训练。使能前应完成患者评估、绑带与关节对齐检查，并用悬吊、支撑架或人工保护稳定设备，避免关节在力矩建立时突然运动。
- 确认任务完成后再进入站立或步态任务；若使能过程中出现异常声响、疼痛、明显错位或报警，应立即按机构急停流程停止，不要反复使能尝试。
- 任务完成标志仅表示执行器已使能，不能作为患者可以负重或开始训练的判断依据。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
