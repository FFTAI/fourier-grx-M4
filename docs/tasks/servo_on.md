# 执行器使能

* TOC
{:toc}

## 任务信息

任务值 (TID)： **35**

任务描述：

- 将所有执行器使能，电机启动输出力矩。

任务参数：

该任务无可配置参数。

## 模块信息

该任务暂无独立模块指令，不支持通过模块接口进行分关节控制。

## 接口信息

状态接口：

| 接口参数   | 接口映射关系                  | 说明                |
|--------|-------------------------|-------------------|
| 任务启动标志 | `task.flag_task_start`  | 使能过程中为 SET        |
| 任务结束标志 | `task.flag_task_finish` | 所有执行器使能完成后置为 SET  |

指令接口：

该任务无需额外指令参数，发送 TID=35 即可触发。

## 原理解释

### 算法运行原理

本任务不生成运动轨迹，而是向全部执行器下发使能命令，使电机进入可输出力矩的状态；任务状态机根据各执行器的响应更新启动、完成标志。使能只是后续位置或力矩控制的前提，并不表示机器人已经处于安全姿态。

### 康复临床使用建议

- 本任务属于治疗前准备或治疗后恢复步骤，不是独立康复训练。使能前应完成患者评估、绑带与关节对齐检查，并用悬吊、支撑架或人工保护稳定设备，避免关节在力矩建立时突然运动。
- 确认任务完成后再进入站立或步态任务；若使能过程中出现异常声响、疼痛、明显错位或报警，应立即按机构急停流程停止，不要反复使能尝试。
- 任务完成标志仅表示执行器已使能，不能作为患者可以负重或开始训练的判断依据。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
