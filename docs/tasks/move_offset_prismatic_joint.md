# 相对调节长度（直线关节、腿长调节关节）

## 任务信息

任务值 (TID): **4207**

任务描述：

- 以**当前实测位置为基准**，按相对偏移量调节腿长（目标位置 = 进入任务时的实测位置 + 偏移量）。
- 与 [调整长度（直线关节）](/fourier-grx-M4/docs/tasks/move_length_prismatic_joint)（绝对位置指令）的区别：
  相对偏移量在关节空间中与标定零点无关，因此**软件重启后未重新标定腿长满点时，也可用于小量程微调**（患者无需下机重新校准）。
- 符号约定与"调整长度"任务一致（指令经 `× -1.0` 转换后下发）。

任务参数：

| 接口参数    | 类型      | 默认值 | 参数范围            | 描述                  |
|---------|---------|-----|-----------------|---------------------|
| 左大腿调节偏移 | `float` | 0.0 | [-0.02, 0.02] | 相对当前位置的调节偏移量，单位为 m。 |
| 左小腿调节偏移 | `float` | 0.0 | [-0.02, 0.02] | 相对当前位置的调节偏移量，单位为 m。 |
| 右大腿调节偏移 | `float` | 0.0 | [-0.02, 0.02] | 相对当前位置的调节偏移量，单位为 m。 |
| 右小腿调节偏移 | `float` | 0.0 | [-0.02, 0.02] | 相对当前位置的调节偏移量，单位为 m。 |

> ⚠️ **注意**：
>
> - 单次指令偏移量限幅为 `±0.02 m`，需要更大幅度调节时请分多次下发，或使用 [调整长度（直线关节）](/fourier-grx-M4/docs/tasks/move_length_prismatic_joint) 任务。
> - 任务的运动过程为开环时间流程（S 曲线），任务结束标志按流程给出。小偏移量（如 0.001 m 级）调节可能因关节摩擦/自锁存在到位误差，请以实际实测位置为准。

## 模块信息

该任务暂无独立模块指令，不支持通过模块接口进行分关节控制。
