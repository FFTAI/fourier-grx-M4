# 被动原地踏步（膝关节受限）

* TOC
{:toc}

## 任务信息

任务值 (TID)： **4302**

任务描述：

- 机器人通过给定参数，生成原地踏步的关节运动轨迹序列，通过执行器跟踪该轨迹，实现被动原地踏步。
- 发送"停止运动标志位"为 true 时，机器人将逐渐停止运动，并不是立即停止。

任务参数：

| 接口参数      | 类型      | 默认值   | 参数范围          | 描述                                         |
|-----------|---------|-------|---------------|--------------------------------------------|
| 大腿长度      | `float` | 0.5   | [0.3, 0.6]    | 机器人的大腿长度，单位为 m。                            |
| 小腿长度      | `float` | 0.5   | [0.3, 0.6]    | 机器人的小腿长度，单位为 m。                            |
| 左腿膝关节受限角度 | `float` | 0.0   | [0.0, 1.0]    | 左腿受限输入，单位为 rad；与右腿输入取较大值后作为双腿共同的最小弯曲参考角。0.0 表示不限制（允许完全伸直）。 |
| 右腿膝关节受限角度 | `float` | 0.0   | [0.0, 1.0]    | 右腿受限输入，单位为 rad；与左腿输入取较大值后作为双腿共同的最小弯曲参考角。0.0 表示不限制（允许完全伸直）。 |
| 抬腿高度      | `float` | 0.1   | [0.1, 0.4]    | 机器人每一步的抬腿高度，单位为 m。                          |
| 步行周期      | `float` | 1.0   | [0.5, 4.0]    | 原地踏步的单步周期，即完成一次完整踏步循环所需的时间，单位为 s。值越小踏步频率越高，值越大踏步越慢。                            |
| 启动运动标志位   | `bool`  | false | (true, false) | 是否启动运动，true 表示启动，false 表示不启动（如果已经启动，不会起作用） |
| 停止运动标志位   | `bool`  | false | (true, false) | 是否停止运动，true 表示停止，false 表示继续行走。             |
| 暂停运动标志位   | `bool`  | false | (true, false) | 是否暂停运动，true 表示暂停，需重启任务才能继续行走。         |

> 说明：`command_switch_1` / `command_param_9` 自 `fourier-grx` v4.4.54 起对本任务生效，启用后任一关节实时力矩持续超过限值 0.1 s（v4.4.75 起）时，机器人立即退出本任务并切换至空闲任务（`TASK_IDLE`），同时置位过力矩保护标志（v4.4.53 及更早版本未执行该判定）。基座高度由膝限位角度与腿长自动计算，`param_6` 不生效。
>
> **膝关节受限角度说明**：
>
> 左右输入为候选受限角，当前实现先取 `θ=max(θ_left,θ_right)`，再将双腿参考膝角截断为不低于 `θ`。该角度作用于算法参考轨迹，不是实际关节的独立机械限位。左右临床限制不同时，应按较大受限需求理解设备的实际行为。
>
> | 受限角度 | 效果                            |
> |------|-------------------------------|
> | 0.0  | 不限制，膝关节可完全伸直（默认）              |
> | 0.3  | 膝关节在运动全程至少保持约 17° 的弯曲         |
> | 0.5  | 膝关节在运动全程至少保持约 28.6° 的弯曲       |
> | 1.0  | 膝关节在运动全程至少保持约 57.3° 的弯曲（限制较强） |

## 原理解释

### 算法运行原理

本任务把膝限几何应用到原地踏步，处理顺序为“**共同受限角 → 基座高度 → 足端周期轨迹 → 逆解与裁剪 → PD 播放**”：

1. **确定共同 `θ` 和 `h`**：当前实现取 `θ=max(θ_left,θ_right)` 用于双膝，通过 `α=atan2(L_s·sinθ,L_t+L_s·cosθ)`、`β=θ−α` 得到 `h=L_t·cosα+L_s·cosβ`。左右接口并不会形成两个独立膝角下限。
2. **生成原地足端运动**：质心相对支撑点不前进，基座高度固定为 `h`。摆动脚垂直轨迹为 `z=h_lift·(1−cos(2πτ))/2`，水平轨迹为 `x=L_max·sin(πτ)`，所以一步结束回到原水平位置；步行周期直接决定左右交替节奏。
3. **逆解并限制膝角**：用 `d=sqrt(dx²+dz²)` 和余弦定理计算两连杆角度，转换到 URDF 后执行 `q_knee=max(q_knee,θ)`，参考速度在逆解阶段由位置序列差分获得。裁剪改变的是参考轨迹，不是对实测位置的反馈钳制。
4. **循环跟踪与调参**：起步进入首帧后循环左右两步，外层一阶平滑和输出限幅仍生效。步内正功率能量超过 70 J 时 PD 向 hard 档爬升，但 `θ` 和已生成的轨迹不会因此重写。
5. **停止与保护**：停止在循环边界进入收尾，力矩保护按持续 0.1 秒超限退出任务。两条支路都不会自动减小 `θ` 或把关节调整到患者舒适位。

### 康复临床使用建议

- 可在外部支撑下用于受限活动范围内的被动踏步，但应先评估双膝伸展范围并设置有安全余量的输入；较大输入会同时用于双腿，需确认另一侧也能耐受，不以该任务强行改善伸直受限。
- 初始采用低抬腿和较长步行周期，观察受限姿态下的左右负重、骨盆代偿和实际膝角，再逐步调整。即使不前进，也仍需悬吊或防跌倒保护。
- 建议启用力矩保护；出现疼痛、痉挛、异常抵抗或左右受力明显不均时停止。软件截断只约束参考值，实际关节是否安全仍须通过实测状态与临床观察判断。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。

## 更新日志

- `fourier-grx` v4.2.6 版本新增该功能。
- `fourier-grx` v4.4.46 版本新增步频上报接口 `rehab.step_frequency`（单位：步/分钟）。
- `fourier-grx` v4.4.54 版本恢复力矩保护判定，`command_switch_1` 与 `command_param_9` 自此生效：任一关节过力矩时立即退出本任务并切换至空闲任务（`TASK_IDLE`）；同时继承 TID 4112 的暂停指令读取，`command_pause` 自此生效。
- `fourier-grx` v4.4.74 版本：本任务触发力矩保护后置位的过力矩保护标志 `flag_robot_torque_protection` 改为**锁存**，不再随任务退出自动清除，需上位机写入 `clear_flag_robot_torque_protection` 清除。保护触发后的动作不变：仍立即退出本任务并切换至空闲任务（`TASK_IDLE`）。
- `fourier-grx` v4.4.75 版本：本任务的软件力矩保护增加 **0.1 s 消抖**——需连续超过「保护力矩限值」达 0.1 s（按控制周期折算：50 Hz 为 5 拍、100 Hz 为 10 拍、200 Hz 为 20 拍）才触发，任一拍回落到限值及以下即清零计数；触发后的动作与标志锁存行为不变。此前为零延时判定，瞬时力矩尖峰可能误退出任务。
- `fourier-grx` v4.4.76 版本：从当前姿态切入步态起始位的过渡时间由 5.0 s 缩短为 **2.5 s**，起步衔接更快（该参数按秒定义，50 / 100 / 200 Hz 机型上的实际时长相同）。继承本控制模型的膝关节受限、助力与前馈变体同样生效。
