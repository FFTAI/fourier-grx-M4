# 设置零点（旋转关节）

* TOC
{:toc}

## 任务信息

任务值 (TID)： **4103**

任务描述：

- 将旋转关节执行器的当前位置设为机械零点，通常用于校准执行器位置。
- 任务按以下顺序自动执行，全程约 11 秒，无需也不接受任何指令参数：

| 步骤 | 动作 | 说明 |
|----|----|----|
| 1 | 执行器下电（`SERVO_OFF`） | 解除力矩输出，关节可自由移动 |
| 2 | 下发绝对编码器清零（`ABSOLUTE_ZERO`） | 由执行器把当前位置记为绝对零位 |
| 3 | 保持 1 秒 | 等待零点写入完成 |
| 4 | 执行器重启（`SERVO_REBOOT`） | 清零后重启执行器 |
| 5 | 等待 10 秒 | 重启期间可能出现通信丢包告警，属正常现象 |

> ⚠️ **注意**：
>
> - 本任务会执行 `SERVO_OFF` → `ABSOLUTE_ZERO` → `SERVO_REBOOT`，全程关节无力矩输出，请确保机器人处于悬挂或安全支撑状态。
> - 重启期间可能短暂出现通信丢包告警，属正常现象。
> - 与「手动校准（旋转关节，TID=4121）」的区别：本任务对**执行器**做绝对编码器清零并重启执行器；4121 只在**软件应用层**记录零点偏置，不下电也不重启。

任务参数：

该任务无可配置参数。

## 模块信息

该任务暂无独立模块指令，不支持通过模块接口进行分关节控制。

## 原理解释

### 算法运行原理

任务先使执行器失能，再把当前编码器位置写入执行器绝对零位，等待写入后重启。其作用是重建设备坐标参考，而不是计算人体关节中立位或测量关节活动度；设零时的机械姿态会直接决定后续 0 rad 参考轨迹的位置。

### 康复临床使用建议

- 该任务包含失能和重启，应在患者下机、设备悬挂或可靠支撑时由受训人员执行，不应作为治疗过程中的姿态微调功能。
- 设零前按工程规范摆放标准机械零位；不要以患者的疼痛位、挛缩位或最大活动范围作为零点。完成后先空载验证左右姿态和关节方向，再允许患者穿戴。
- 若同一设备校准后反复出现左右不对称或异常轨迹，应停止临床使用并检查机械装配、编码器和校准流程，而非频繁重新设零掩盖问题。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
