# 被动前向行走 谐波拟合（膝受限）

## 任务信息

| 任务 | 任务值 (TID) | 控制方式 |
|---|---|---|
| 被动前向行走 谐波拟合 | **4131** | PD |
| 被动前向行走 谐波拟合 + 速度前馈 | **4113** | PD + 速度前馈 |
| 被动前向行走 谐波拟合 · POSITION + 速度前馈 | **4127** | POSITION + 速度前馈 |

适用机型：M4L（P1 / T1 / T2）。对应规划器 **4407**。助力版本为 **4310（PD）/ 4311（dt）**，对应规划器 **4510 / 4511**。

> 本页是 **4131 在膝受限任务组中的使用入口，不新增任务编号**。这里的膝受限由 `param_2` 选择系数表自带的伸膝限制等级，不等同于 4310 / 4311 的额外虚拟用户膝角下限。

任务描述：

- 轨迹与[被动前向行走 谐波拟合（4131）](/fourier-grx-M4/docs/tasks/rotary_joint_forward_walk_harmonic)完全相同，从 4 个髋幅度档 × 4 个系数表伸膝限制档组成的 16 条曲线中选择，并由独立步频档控制节奏。
- `param_2` 的 1 / 2 / 3 / 4 档对应膝角伸直底线 **0 / 5 / 10 / 15°**。髋曲线也随之变化，不是只简单裁剪膝角。
- 不读取虚拟用户 `knee_restriction_left/right`，也不根据腿长重新计算基座高度。需要在这类系数表限制之外再施加虚拟用户膝角下限时，请使用 **4310 / 4311**。
- 步长、步速、腿长、基座高度、抬脚高度和双支撑占比不参与曲线生成；`param_6` 不生效。
- POSITION 变体走执行器位置环，参数相同；PD 速度前馈仅在 T2 的 FSA v3 协议上实际生效，P1/T1 的 FSA v2 fast 帧没有速度字段。

任务参数：

| 面板参数 | 含义 | 默认值 | 说明 |
|---|---|---|---|
| `param_1` | 髋摆动幅度等级 | 2 | 1～4 档，选择系数表轨迹形状 |
| `param_2` | 系数表伸膝限制等级 | 1 | 1～4 档，对应 0 / 5 / 10 / 15° |
| `param_3` | 步频等级 | 3 | 1～6 档；目标大步时间 5.25～3.0 s，≤0 沿用当前档 |
| `param_6` | 基座高度 | — | 本任务不生效 |
| 启动 / 停止 / 暂停 | 运动控制 | false | 与 4131 相同；暂停后需重启任务继续 |
| `switch_1` / `param_9` | 力矩保护 | 未启用 | 启用后，任一关节力矩连续超限 0.1 s 即退出任务并锁存保护标志 |

> 档位在任务进入后、启动之前生效。行走过程中修改不影响当前轨迹，下一次起步时才重新生成。实际周期按机型控制周期量化，以 `rehab.gait_stride_time_s` 上报值为准。

## 接口信息

| 参数 | 接口映射 |
|---|---|
| 幅度 / 系数表膝限 / 步频 | `grx.virtual_panel_command_param_1` / `param_2` / `param_3` |
| 启动 / 停止 / 暂停 | `grx.virtual_panel_command_start` / `stop` / `pause` |
| 力矩保护 | `grx.virtual_panel_command_switch_1` / `grx.virtual_panel_command_param_9` |
| 参考轨迹、进度与步频 | `rehab.reference_joint_*`、`rehab.motion_ratio`、`rehab.step_frequency` |
| 系数表膝限回显 | `rehab.gait_knee_restriction_deg`（0 / 5 / 10 / 15°） |
| 实际大步时间 | `rehab.gait_stride_time_s` |

## 原理解释

4131 直接根据预存 Fourier 系数重建关节曲线，不做在线质心、足端或两连杆逆运动学计算。`param_2` 选择已包含特定膝角伸直底线的系数表，而不是在生成后再施加额外裁剪。虚拟用户腿长和左右膝限不参与这一过程。

需要叠加额外膝角下限时，4310 / 4311 会先按同样方式选择系数表，再对左右膝角施加 `θ=max(θ_left,θ_right)` 并重新差分速度。两种机制不能混为一谈。

### 康复临床使用建议

先根据患者实际膝伸展活动范围选择系数表档位，并用规划器 4407 预览关节包络。档位限制只作用于参考轨迹，不是患者实际关节的独立机械限位，也不能代替外部支撑、力矩保护和治疗师评估。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
