# 谐波系数助力前向行走（调整 dt 参数）

* TOC
{:toc}

## 任务信息

任务值 (TID)： **4133**（v4.4.79 起新增）

适用机型：M4L（P1 / T1 / T2）

任务描述：

- 步态来源与[谐波系数前向行走（4131）](/fourier-grx-M4/docs/tasks/rotary_joint_forward_walk_harmonic)完全一致：回放 Fourier-GRX 主表（预存的 Fourier 谐波系数）采样出的周期性关节曲线，**曲线形状固定**（由幅度档与伸膝限制档从 16 条曲线中选定），**节奏**由步频档决定。
- 助力语义与[助力前向行走（调整 dt 参数，4118）](/fourier-grx-M4/docs/tasks/forward_walk_assist_adjust_dt)一致：助力系数映射到轨迹**播放速度**（play_speed ∈ [0.5, 1.0]），系数越大播放越快（越接近所选步频档位的正常节奏）；系数越小播放越慢，给患者更多时间跟随运动。可启用自动助力模式，由算法根据实测关节力矩自动增减助力系数。
- 与 4118 的差别：**4118 的轨迹由 LIPM 模型按步长/步速在线生成，本任务的轨迹固定来自系数表**；因此本任务没有步长/步速/基座高度/抬腿高度/双支撑期占比参数，面板前三档与 4131 完全相同（幅度档 / 伸膝限制档 / 步频档），助力系数挪到 `param_4`。
- 本任务 PD 增益**全程固定 medium 档**（与 4118 相同：助力场景人主动、机器跟随调步频，hard 档太硬、与人较劲），不随负载变化。
- 本任务**只指令关节角度，不指令位移**：基座（骨盆）的前进量不由算法给出，实际走多远取决于使用者与外骨骼的整体运动。

任务参数：

| 接口参数       | 类型      | 默认值   | 参数范围       | 描述                                                                                     |
|------------|---------|-------|------------|----------------------------------------------------------------------------------------|
| 髋摆动幅度等级   | `int`   | 2     | [1, 4]     | 同 4131：选择轨迹形状的第一条轴，四档差异几乎全在髋的摆动幅度上。非法值或未发送时取默认档 2。                       |
| 伸膝限制等级    | `int`   | 1     | [1, 4]     | 同 4131：1/2/3/4 档对应膝关节伸直底线 0 / 5 / 10 / 15°。越界会被限幅到 1..4。                                     |
| 步频等级      | `int`   | 3     | [1, 6]     | 同 4131：决定轨迹的"正常节奏"。1 档最慢（5.25 s/大步）到 6 档最快（3.0 s/大步）。非法值或 ≤ 0 时保持当前档不变。           |
| 助力系数      | `float` | 0.0   | [0.0, 1.0] | 轨迹播放速度的调节系数（play_speed = 0.5 + 系数 × 0.5）。0 = 0.5 倍速最慢，1 = 所选步频档位的正常速度。未发送时按 0 处理。        |
| 自动助力模式标志位 | `bool`  | false | (true, false) | 是否启用自动助力模式（switch_1）。启用后由算法在每个控制周期判定：在摆动相中，若实测髋关节力矩超过「重力补偿力矩 + 2.0 Nm」则助力系数 +0.02，低于「重力补偿力矩」则 -0.01，无需手动设定；助力系数始终限制在 [0.0, 1.0] 范围内。启用后 `param_4` 不再起作用。 |
| 启动运动标志位   | `bool`  | false | (true, false) | 是否启动运动。true 表示启动（若已启动则不起作用）。                                                             |
| 停止运动标志位   | `bool`  | false | (true, false) | 是否停止运动。true 表示走满当前循环窗后停止。                                                                 |

> **不生效的参数**：大腿长度、小腿长度、步长长度、步行速度、基座高度、抬腿高度、双支撑期占比（本任务曲线来自预存系数表，不做运动学/动力学反解，摇杆左右推同样不改变轨迹，只用于触发启动/停止）。

> 生效时机：
>
> - **助力系数 / 自动助力模式**在行走过程中实时生效（每个控制周期刷新 play_speed）。
> - **幅度档 / 伸膝限制档 / 步频档**在按下"启动"前修改立即用于本次起步；行走过程中修改不影响正在执行的轨迹，下一次起步才生效（与 4131 相同）。

## 原理解释

### 算法运行原理

本任务不改变谐波曲线本身，而是改变**相位时间轴的推进速度**：

1. **基础轨迹**：幅度、伸膝限制和步频档先确定 `q(φ)` 与基准周期 `T_stride`，其原理与 TID 4131 相同。助力计算发生在该轨迹已经生成之后，不重新拟合 Fourier 系数。
2. **时间缩放**：手动模式将助力系数 `r` 映射为 `v_play=0.5+0.5r`，每个控制周期推进 `Δt_motion=Δt_control·v_play`。因此实际周期近似为 `T_actual=T_base/v_play`：`r=0` 时周期约加倍，`r=1` 时恢复所选步频档的基准节奏。Kp/Kd 始终固定 medium 档，不随 `r` 改变。
3. **自动助力判定**：只在循环段且某侧处于摆动相时检查该侧髋。若重力项 `G>0`、髋参考速度为负，并且实测力矩 `τ>G+2.0 Nm`，则 `r←r+0.02`；若 `τ<G`，则 `r←r−0.01`；其他相位或方向保持不变，最后将 `r` 限幅到 `[0,1]`。增加和减小采用不同步长，因此升速通常比降速更快。
4. **反馈作用位置**：力矩反馈只改变后续轨迹索引的推进速度，不直接叠加辅助力矩，也不修改当前周期的角度包络。实测力矩同时包含设备与患者因素，所以该规则是启发式节奏调节，而非患者意图识别或按需助力的一般证明。

### 康复临床使用建议

- 低助力系数表示更慢、更易跟随的节奏，并不表示更低关节刚度或更小被动活动幅度。对需要更多反应时间的患者，可先降低播放速度，再依据耐受逐步接近所选档位的正常节奏。
- 自动助力利用的是关节总力矩，其中还可能包含设备重力、摩擦和运动惯性，不能直接解释为患者的主动肌力或运动意图。启用后治疗师仍须观察节奏变化，出现突然加速、疲劳或动作质量下降时及时停止并改用手动参数。
- 先确定合适的固定曲线、伸膝限制和基础步频，再调节奏；不要同时提高步频档与助力系数。外部支撑和连续临床监护仍然必需。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
