# 执行器失能

* TOC
{:toc}

## 任务信息

任务值 (TID)： **36**

任务描述：

- 将所有执行器失能，电机停止输出力矩。

任务参数：

该任务无可配置参数。

## 模块信息

该任务暂无独立模块指令，不支持通过模块接口进行分关节控制。

## 接口信息

状态接口：

| 接口参数   | 接口映射关系                  | 说明               |
|--------|-------------------------|------------------|
| 任务启动标志 | `task.flag_task_start`  | 失能过程中为 SET       |
| 任务结束标志 | `task.flag_task_finish` | 所有执行器失能完成后置为 SET |

指令接口：

该任务无需额外指令参数，发送 TID=36 即可触发。执行器失能后机器人将瘫软，请确保已做好机械支撑或安全保护。

## 原理解释

### 算法运行原理

本任务同样工作在 `ACTUATOR_SPACE`，通过控制模式切换消除主动力矩，而不是规划一条“回到安全姿态”的轨迹：

1. 进入任务时向目标执行器发送 `SERVO_OFF`，并清空位置、速度、力矩和电流目标；单腿校准等内部流程也可只传入部分执行器索引。
2. 下一阶段以 `EFFORT` 模式写入零力矩，随后恢复 `NONE`，确保不会继续继承此前的力矩指令。
3. 状态机结束后切回 `TASK_IDLE`。整个过程没有位置反馈控制、重力补偿或速度阻尼，关节之后主要受重力、摩擦和外部支撑约束。

所以失能不等于受控制动：设备可能快速下垂，也可能因机械摩擦而暂时停留在原处，这两种情况都不由本任务主动调节。

### 康复临床使用建议

- 仅在患者和设备已由悬吊、支撑架或操作人员可靠承托后执行，尤其不能把失能当作“保持站立”或“缓慢结束训练”的方式。
- 治疗结束失能前，应先停止步态任务并确认患者处于稳定、可转移的姿态；失能后再按流程卸除绑带或转移患者。
- 紧急情况应遵循设备急停流程。失能后若需恢复训练，应重新检查姿态、零点和故障状态，而不是直接续接原训练。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
