# 助力前向行走 谐波拟合（PD 模式）

* TOC
{:toc}

## 任务信息

| 任务 | 任务值 (TID) | 控制方式 |
|---|---|---|
| 助力前向行走 谐波拟合（PD 模式） | **4132** | 助力（PD 模式） |

适用机型：M4L（P1 / T1 / T2）

任务描述：

- 步态来源与[被动前向行走 谐波拟合（4131）](/fourier-grx-M4/docs/tasks/rotary_joint_forward_walk_harmonic)完全一致：回放 Fourier-GRX 主表（预存的 Fourier 谐波系数）采样出的周期性关节曲线，**曲线形状固定**（由幅度档与伸膝限制档从 16 条曲线中选定），**节奏**由步频档决定。
- 助力语义与[助力前向行走（PD 模式，4116）](/fourier-grx-M4/docs/tasks/forward_walk_assist_adjust_pd)一致：助力系数在 buttery（最柔顺）与 soft（最软一档）之间对 PD 增益做线性插值，系数越小关节越柔顺、患者自主发力空间越大。
- 与 4116 的差别：**4116 的轨迹由 LIPM 模型按步长/步速在线生成，本任务的轨迹固定来自系数表**；因此本任务没有步长/步速/基座高度/抬腿高度/双支撑期占比参数，面板前三档与 4131 完全相同（幅度档 / 伸膝限制档 / 步频档），助力系数挪到 `param_4`。
- 负载检测与自动 PD 爬升在本任务中关闭（助力档位由上位机直接给定）。
- 本任务**只指令关节角度，不指令位移**：基座（骨盆）的前进量不由算法给出，实际走多远取决于使用者与外骨骼的整体运动。

任务参数：

| 接口参数       | 类型      | 默认值   | 参数范围       | 描述                                                                                     |
|------------|---------|-------|------------|----------------------------------------------------------------------------------------|
| 髋摆动幅度等级   | `int`   | 2     | [1, 4]     | 同 4131：选择轨迹形状的第一条轴，四档差异几乎全在髋的摆动幅度上。非法值或未发送时取默认档 2。                       |
| 伸膝限制等级    | `int`   | 1     | [1, 4]     | 同 4131：1/2/3/4 档对应膝关节伸直底线 0 / 5 / 10 / 15°。越界会被限幅到 1..4。                                     |
| 步频等级      | `int`   | 3     | [1, 6]     | 同 4131：只改节奏、不改曲线形状。1 档最慢（5.25 s/大步）到 6 档最快（3.0 s/大步）。非法值或 ≤ 0 时保持当前档不变。          |
| 助力系数      | `float` | 0.0   | [0.0, 1.0] | 关节 PD 控制刚度的调节系数。0 = buttery 最柔顺，1 = soft 最软一档（插值公式与档位表与 4116 完全相同，见[其文档](/fourier-grx-M4/docs/tasks/forward_walk_assist_adjust_pd)）。未发送时按 0 处理。 |
| 启动运动标志位   | `bool`  | false | (true, false) | 是否启动运动。true 表示启动（若已启动则不起作用）。                                                             |
| 停止运动标志位   | `bool`  | false | (true, false) | 是否停止运动。true 表示走满当前循环窗后停止。                                                                 |

> **不生效的参数**：大腿长度、小腿长度、步长长度、步行速度、基座高度、抬腿高度、双支撑期占比（本任务曲线来自预存系数表，不做运动学/动力学反解，摇杆左右推同样不改变轨迹，只用于触发启动/停止）。

> 生效时机：
>
> - **助力系数**只在任务进入启动阶段（`STAGE_INIT` / `STAGE_START`）时写入关节 PD 增益，行走过程中修改不会立即改变当前刚度，需停止后重新启动本任务才生效（与 4116 相同）。
> - **幅度档 / 伸膝限制档 / 步频档**在按下"启动"前修改立即用于本次起步；行走过程中修改不影响正在执行的轨迹，下一次起步才生效（与 4131 相同）。

## 原理解释

### 算法运行原理

本任务由两个相对独立的计算支路组成：**谐波轨迹生成**决定“要走到哪里”，**可调 PD**决定“以多大刚度把关节拉回轨迹”。

1. **参考轨迹支路**：与 TID 4131 相同，按 `q(φ)=a0+Σ(a_k·cos(2πkφ)+b_k·sin(2πkφ))` 重建所选曲线；幅度和伸膝限制选择系数，步频档通过整帧周期改变相位推进速度。该支路不读取助力系数，所以改变助力不会拉伸或平移参考轨迹。
2. **助力增益插值**：将助力系数记为 `r∈[0,1]`，启动阶段计算 `Kp=100+(200−100)r`、`Kd=10+(20−10)r`。这组增益随后用于 `τ≈Kp(q_ref−q_meas)+Kd(ω_ref−ω_meas)`，同样的位置或速度误差在 `r` 较大时产生更强纠偏力矩。
3. **与被动谐波任务的差别**：本任务显式关闭负载能量检测和自动 PD 爬升，避免自动调参与手动助力相互覆盖；因此整个任务中的刚度只由启动时锁存的 `r` 决定。
4. **生效边界**：插值只在 `STAGE_INIT/STAGE_START` 执行，运行中的轨迹索引会继续前进，但不会重新读取 `r` 更新 Kp/Kd。必须停止并重新启动后，新系数才会进入控制环。

所以 `r=0` 并不是“零力矩”，而是使用 buttery 档最低预设增益；`r=1` 也不是额外前馈助力，而是 soft 档较强的误差反馈。

### 康复临床使用建议

- 若训练目标是增加主动参与，可在保证安全和动作质量的前提下逐步降低助力系数；若患者尚不能耐受轨迹偏差，可提高引导强度。调整后应停止并重新启动，不能将界面新数值误认为当前已生效。
- 较低刚度只是为自主运动留出空间，并不表示算法能识别患者意图或准确量化主动用力。治疗师应结合实测轨迹偏差、代偿、疲劳和主观感受评估，而非仅看助力系数。
- 先以低幅度、慢节奏建立耐受，再调刚度；伸膝限制须按临床活动范围设置。整个过程中仍需外部防跌倒保护，固定轨迹和 PD 控制都不能保证患者平衡。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
