# 高抬腿 DSP 助力前向行走

## 任务信息

| 任务 | 任务值 (TID) | 控制方式 |
|---|---|---|
| 高抬腿 DSP 助力前向行走（调 PD） | **4136** | 助力调 PD |
| 高抬腿 DSP 助力前向行走（调 dt） | **4137** | 助力调 dt |

适用机型：M4L（P1 / T1 / T2）。

任务描述：

- 轨迹与[高抬腿 DSP 前向行走（4134 / 4135）](/fourier-grx-M4/docs/tasks/forward_walk_high_lift)完全一致：在普通 DSP 前向行走的基础上补偿摆动脚抬升高度。本页只说明助力执行部分的差异，轨迹生成、参数含义与算法原理见该页。
- 4136（调 PD）：助力系数在 buttery（最柔顺）与 soft（最软一档）之间对关节 PD 增益做线性插值，只在启动阶段写入一次；语义与[助力前向行走（PD 模式，4116）](/fourier-grx-M4/docs/tasks/forward_walk_assist_adjust_pd)一致。
- 4137（调 dt）：助力系数映射为 0.5～1.0 倍的轨迹回放速度，系数越大越接近正常步速；可用 `switch_1` 打开自动助力。语义与[助力前向行走（dt 模式，4118）](/fourier-grx-M4/docs/tasks/forward_walk_assist_adjust_dt)一致。
- 启动、停止、摇杆与 Dynalink 上报分别沿用[助力前向行走（PD 模式，4116）](/fourier-grx-M4/docs/tasks/forward_walk_assist_adjust_pd)与[助力前向行走（dt 模式，4118）](/fourier-grx-M4/docs/tasks/forward_walk_assist_adjust_dt)。本页任务不读取 `param_9`（过力矩保护），也不提供暂停接口。

## 任务参数

面板参数沿用被动版本的步长 / 步速 / 抬脚目标 / 基座高度 / 原始抬升 / 双支撑期，并把助力系数放到 `param_4`：

| 面板参数 | 含义 | 默认值 | 说明 |
|---|---|---|---|
| `param_1` | 步长 | 0.5 m | 与普通前向行走一致 |
| `param_2` | 步行速度 | 0.5 m/s | 与普通前向行走一致 |
| `param_3` | 最终实际离地峰值目标 | 10 cm | 单位 cm，允许范围 5～25 cm；≤0 或未发送时沿用当前值；生成器反解原始目标，使平滑后的实际峰值进入目标 ±5 mm 容差 |
| `param_4` | 助力系数 | 0 | 范围 [0.0, 1.0]，未发送时按 0 处理。4136：0 = buttery 最柔顺，1 = soft 最软一档；4137：0 = 0.5 倍速最慢，1 = 1.0 倍速 |
| `param_6` | 基座高度 | 自动 | 与普通前向行走一致 |
| `param_7` | DSP 原始足端抬升高度 | 0.10 m | 作用于补偿前的 DSP 轨迹，与 `param_3` 的最终离地目标不同 |
| `param_8` | 双支撑期占比 | 0.2 | 仅 DSP 生成参数 |
| `switch_1` | 自动助力模式（仅 4137） | 未启用 | 启用后按实测髋关节力矩自动增减助力系数，`param_4` 不再起作用（与 4118 相同） |

`lift_peak_phase` 与 `lift_smooth_time` 是算法开发参数，分别控制摆动区间内的峰值相位与最终髋 / 膝轨迹的平滑时间，不通过面板下发。

> 4136 的助力系数只在任务进入启动阶段时写入关节 PD 增益，行走过程中修改不会立即改变当前刚度，需停止后重新启动本任务才生效（与 4116 相同）。4137 的助力系数与自动助力在行走过程中实时生效，每个控制周期刷新回放速度（与 4118 相同）。

> 轨迹生成相关参数（`param_1` / `param_2` / `param_3` / `param_6` / `param_7` / `param_8`）在任务进入后、启动之前生效；行走过程中修改不会影响当前轨迹，下一次起步时按新参数重新生成。接近直腿或触及关节行程限制时，实际抬脚峰值可能低于目标。

## 接口信息

状态与指令接口分别同 4116 / 4118；助力系数改走 `param_4`（`param_3` 已被目标抬脚峰值占用）：

| 参数 | 接口映射 |
|---|---|
| 目标抬脚峰值 | `grx.virtual_panel_command_param_3` |
| 助力系数 | `grx.virtual_panel_command_param_4` |
| 自动助力模式（仅 4137） | `grx.virtual_panel_command_switch_1` |
| 启动 / 停止 | `grx.virtual_panel_command_start` / `stop` |
| 当前助力系数 | `rehab.assist_ratio` |
| 参考轨迹、进度与步频 | `rehab.reference_joint_*`、`rehab.motion_ratio`、`rehab.step_frequency` |

> ⚠️ 与 4116 / 4118 不同：本任务的**助力系数在 `param_4`**（`param_3` 已被目标抬脚峰值占用）；`param_1` / `param_2` 仍是步长 / 步行速度。上位机按本表映射，勿沿用 4116 / 4118 的参数位置。

## 原理解释

### 算法运行原理

高抬腿轨迹与被动版本共用同一套生成器：先在摆动区间按目标离地高度重解髋 / 膝角，再做零相位平滑，最后进入普通 DSP 的起步、循环、收尾与 PD 控制流程，详见[高抬腿 DSP 前向行走 · 原理解释](/fourier-grx-M4/docs/tasks/forward_walk_high_lift#原理解释)。助力版本只改变执行阶段：

1. **4136（调 PD）**：启动阶段把助力系数 `r∈[0,1]` 插值到 buttery 与 soft 两组 PD 增益之间（档位表与 4116 相同），整个行走过程保持该刚度；运行中修改 `param_4` 不会重新读取。负载检测与自动 PD 爬升在本任务中显式关闭。
2. **4137（调 dt）**：播放速度 `v_play=0.5+0.5r`，轨迹时间按 `Δt_motion=Δt_control·v_play` 推进，因此助力越大步态周期越短；自动助力按实测髋关节力矩增减系数（判定逻辑与 4118 相同），PD 全程固定 medium 档。

### 康复临床使用建议

- 需要更大摆动脚间隙、同时希望保留主动参与时，可先按被动高抬腿页的建议确定目标抬脚峰值，再调整助力系数；两类参数不要同时大幅变化。
- 4136 降低刚度只是为自主运动留出空间，并不表示算法能识别患者意图；4137 的“助力增加”指回放加快，不是输出更大辅助力矩。两者都不能替代平衡与防跌倒保护。
- 调参后应重新启动任务确认实际生效：4136 的刚度只在启动时锁存，4137 的节奏变化需观察实际步态周期。若出现疼痛、支撑侧不稳或明显不对称，应降低目标或回到普通 DSP 任务并重新评估。

> 临床建议仅供专业人员参考，不替代医生/治疗师评估、产品说明书及医疗机构安全规范。
