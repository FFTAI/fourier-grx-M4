# 被动前向行走

## 任务信息

任务值 (TID): **4129**（v4.4.69 起；此前为 4111）

任务描述：

- 机器人通过给定参数，生成向前行走的关节运动轨迹序列，通过执行器跟踪该轨迹，实现被动前向行走。
- 发送"停止运动标志位"为 true 时，机器人将逐渐停止运动，并不是立即停止。
- 触发力矩保护后，机器人立即退出本任务并切换至空闲任务（`TASK_IDLE`），同时置位过力矩保护标志，需重新下发本任务才能继续行走。

任务参数：

| 接口参数     | 类型      | 默认值   | 参数范围          | 描述                                         |
|----------|---------|-------|---------------|--------------------------------------------|
| 大腿长度     | `float` | 0.5   | [0.3, 0.6]    | 机器人的大腿长度，单位为 m。                            |
| 小腿长度     | `float` | 0.5   | [0.3, 0.6]    | 机器人的小腿长度，单位为 m。                            |
| 步长长度     | `float` | 0.5   | [0.2, 0.8]    | 机器人每一步的长度，单位为 m。                           |
| 步行速度     | `float` | 0.5   | [0.1, 1.2]    | 机器人前进的目标速度，单位为 m/s。单步持续时间 = 步长 ÷ 步行速度（例如步长 0.5 m、步速 0.5 m/s 时，单步用时约 1.0 s）。 |
| 基座高度     | `float` | None  | [0.6, 1.2]    | 行走时基座（骨盆）离地高度，单位为 m。≤ 0 或未发送时自动取大腿+小腿长度之和。超出范围会被限幅到该范围内。下次起步（轨迹重新生成）时生效，行走过程中修改不影响当前正在执行的轨迹。 |
| 抬腿高度     | `float` | 0.1   | [0.05, 0.2]   | 摆动脚最大抬升高度，单位为 m。≤ 0 或未发送时使用默认值。超出范围会被限幅到该范围内。下次起步（轨迹重新生成）时生效，行走过程中修改不影响当前正在执行的轨迹。 |
| 双支撑期占比   | `float` | 0.2   | [0.1, 0.3]    | 双支撑期时间占单步周期的比例。≤ 0 或未发送时使用默认值。超出范围会被限幅到该范围内。本任务使用 DSP 步态生成器，该参数生效（PD / dt 助力类任务使用 vhip 生成器，该参数不生效）。下次起步（轨迹重新生成）时生效，行走过程中修改不影响当前正在执行的轨迹。 |
| 启动运动标志位  | `bool`  | false | (true, false) | 是否启动运动，true 表示启动，false 表示不启动（如果已经启动，不会起作用） |
| 停止运动标志位  | `bool`  | false | (true, false) | 是否停止运动，true 表示停止，false 表示继续行走。             |
| 暂停运动标志位  | `bool`  | false | (true, false) | 是否暂停运动，true 表示暂停，需重启任务才能继续行走。              |
| 启用力矩保护开关 | `bool`  | false | (true, false) | 是否启用力矩保护功能                                 |
| 保护力矩限值   | `float` | None  | [0.0, 200.0]  | 行走过程中任意关节允许的最大输出力矩，单位为 Nm。当任一关节实时力矩超过此限值时，机器人立即退出本任务并切换至空闲任务（`TASK_IDLE`），同时置位过力矩保护标志。仅在启用力矩保护时生效，默认不启用。           |

> 建议：
> - 步长为步速的 0.5 到 1.0 倍之间，能够获得较好的行走效果。例如，步速为 0.5 m/s 时，步长建议设置在 0.25 m 到 0.5 m 之间。

## 模块信息

该任务暂无独立模块指令，不支持通过模块接口进行分关节控制。

## 接口信息

状态接口：

| 接口参数      | 接口映射关系                               | 
|-----------|--------------------------------------|
| 任务启动标志    | `task.flag_task_start`               |
| 任务结束标志    | `task.flag_task_finish`              |
| 任务暂停标志    | `task.flag_task_pause`               |
| 运行比例      | `rehab.motion_ratio`                 |
| 步频          | `rehab.step_frequency`              |
| 参考轨迹位置    | `rehab.reference_joint_position`     |
| 参考轨迹速度    | `rehab.reference_joint_velocity`     |
| 参考轨迹位置最大值 | `rehab.reference_joint_position_max` |
| 参考轨迹位置最小值 | `rehab.reference_joint_position_min` |

> 说明：`reference_joint_position_max`/`reference_joint_position_min` 自 v4.4.32 起，仅统计"循环走路/踏步"稳态阶段的关节角度范围，不包含起步、收尾过渡阶段的瞬态极值。

指令接口：

- 大腿长度 在算法运算中只能输入一个值，因此取左右大腿长度的均值。因此，传参时传入两个，但是实际只会取均值去使用。
- 小腿长度 在算法运算中只能输入一个值，因此取左右小腿长度的均值。因此，传参时传入两个，但是实际只会取均值去使用。

| 接口参数     | 接口映射关系                                                                                   |
|----------|------------------------------------------------------------------------------------------|
| 大腿长度     | `grx.virtual_user_upper_leg_length_left`, `grx.virtual_user_upper_leg_length_right`, 取均值 |
| 小腿长度     | `grx.virtual_user_lower_leg_length_left`, `grx.virtual_user_lower_leg_length_right`, 取均值 |
| 步长长度     | `grx.virtual_panel_command_param_1`                                                      |
| 步行速度     | `grx.virtual_panel_command_param_2`                                                      |
| 基座高度     | `grx.virtual_panel_command_param_6`                                                      |
| 抬腿高度     | `grx.virtual_panel_command_param_7`                                                      |
| 双支撑期占比   | `grx.virtual_panel_command_param_8`                                                      |
| 启动运动标志位  | `grx.virtual_panel_command_start`                                                        |
| 停止运动标志位  | `grx.virtual_panel_command_stop`                                                         |
| 暂停运动标志位  | `grx.virtual_panel_command_pause`                                                        |
| 启用力矩保护开关 | `grx.virtual_panel_command_switch_1`                                                     |
| 保护力矩限值   | `grx.virtual_panel_command_param_9`                                                      |

## 更新日志

- `fourier-grx` v4.0.0 版本新增该功能。
- `fourier-grx` v4.4.46 版本新增步频上报接口 `rehab.step_frequency`（单位：步/分钟）。
- `fourier-grx` v4.4.48 版本新增基座高度/抬腿高度/双支撑期占比参数接口。
- `fourier-grx` v4.4.65 版本新增两个前馈变体任务：位置环 + 速度前馈（TID 4124）与 PD + 速度前馈（TID 4126）。速度前馈由实际下发目标数值微分生成；POSITION 变体走执行器位置环（PID 参数见机型参数类），PD 变体由 kd × 目标速度等效为前馈力矩（注意：FSA v2 协议无 velocity 字段，PD 前馈仅 M4LT2 生效）。
- `fourier-grx` v4.4.68 版本：M4LT2 控制频率提至 200 Hz（`control_period` 0.01 → 0.005），本任务的参考轨迹总延迟补偿随之由 0.12 s 收小为 0.06 s（按控制周期折算帧索引）；hard 档整定为 kp `[1000,1000,1000,1000]` / kd `[60,60,60,60]`（髋 ζ=0.63 空载 / 0.52 载人，膝 ζ=1.12 / 1.04 过阻尼）。同时修复本任务的前馈变体（TID 4124 / 4126）速度前馈因任务默认以 `STANDALONE` 方式调度而从未生效的问题。
- `fourier-grx` v4.4.69 版本：为把前馈变体按控制模式归族，本任务 TID 由 **4111** 改为 **4129**，而 **4111 现在指向本任务的 PD + 速度前馈变体**（原为 4126）；本任务的 POSITION 变体由 4124 顺移至 **4125**。⚠️ 上位机需同步——沿用 4111 会调用到前馈变体而非本任务。前馈家族本版由 4 个扩充到 8 个（另含正弦轨迹与谐波走路的变体）。
- `fourier-grx` v4.4.70 版本：hard 档提至 kp `[1500×4]` / kd `[90×4]`（髋 ζ=0.77 空载 / 0.64 载人，膝 ζ=1.37 / 1.28），本任务的负载检测 PD 爬升因此跨度更大，约 8.7 s（T2）/ 10.1 s（T1）到顶；步态平滑滤波截止 2.5 → 8.0 Hz（群延迟约 15–17 ms），参考轨迹总延迟补偿 0.06 → 0.03 s。⚠️ 键盘触发行走时的默认速度由 0.25 提到 0.5 m/s，步长不变时步频翻倍。hard 刚度提高后，触发 140 N·m 过力矩保护所需的跟踪误差由约 8° 降至约 5.3°。
- `fourier-grx` v4.4.71 版本：**回退 v4.4.70 的整定**，hard 档回到 kp `[1000×4]` / kd `[60×4]`（髋 ζ=0.63 空载 / 0.52 载人，膝 ζ=1.12 / 1.04）、步态平滑滤波截止回到 2.5 Hz、参考轨迹总延迟补偿回到 0.06 s、负载检测 PD 爬升下限回到 0.01。触发 140 N·m 过力矩保护所需的跟踪误差随之回到约 8°。⚠️ 但键盘触发行走时的默认速度**维持 0.5 m/s 未回退**（相对 4.4.69 仍是步频翻倍），需要慢速请用面板或上位机调整速度参数。
