# 贡献指南

欢迎通过 [Issue](https://github.com/FFTAI/fourier-grx-M4/issues) 或 Pull Request 改进文档与示例。无论是修正错别字、澄清操作步骤，还是补充接口说明，都请尽量提供可核对的信息。

## 反馈问题

提交 Issue 时，建议包含：

- 相关文档页面的 URL 或仓库文件路径。
- 当前内容存在的问题，以及期望的修正或补充。
- 涉及机器人行为或接口时，注明机器人型号、`fourier-grx` 版本和运行模式。
- 涉及示例代码时，注明运行目录、执行的命令、完整错误信息和开发环境；请勿提交密码、令牌等敏感信息。

## 提交修改

1. 将修改控制在清晰、集中的主题内，避免同时夹杂无关的全文格式化。
2. 修改中文页面时，同步更新 `docs/en/` 下的英文对应页面；修改示例时，同时检查相关示例文档是否仍然准确。
3. 对照实际命令、配置和代码路径核对技术内容，不要将未经验证的推断写成确定事实。
4. 在 Pull Request 中概述修改内容、涉及页面和已完成的检查；涉及行为变更时，请附核对依据。

## 文档约定

- 页面通常需要 `layout: default`、`title` 和 `nav_order`；子页面还需要正确的 `parent`，父页面按现有导航结构配置 `has_children`。
- 文档页中的站内链接和资源路径通常以 `/fourier-grx-M4/` 开头；根目录 README 使用仓库相对路径。
- 新增任务页面时，同步维护中英文任务总表、任务索引及相关接口映射，不要只增加孤立页面。
- 命令、文件名、接口字段和版本号使用行内代码格式，并保持中英文页面的技术内容一致。

## 提交前检查

本仓库没有已检入的统一构建、测试或 lint 工具链。提交文档修改前，请至少检查：

- 新增或修改的站内链接、图片和其他资源路径是否有效。
- 页面 front matter 是否符合所在章节的导航结构。
- `docs/` 与 `docs/en/` 的对应页面是否同步。
- 示例命令、运行目录、依赖和安全前提是否清楚且与当前代码一致。

感谢所有帮助改进 Fourier-GRX-M4 SDK 文档与示例的贡献者。
