# 设备集成

本栏目说明如何把第三方设备（脑电、BCI、外接传感器、研究用上位机）接入 `fourier-grx` 或 M4 上位机。这里的“集成”指工程和数据链路，不构成医疗适用范围或疗效声明。

## 当前页面

- [脑电 / BCI 联合使用示例](/fourier-grx-M4/docs/integrations/eeg_bci)：M4 上位机的 EEG TCP 接入协议，以及自定义 BCI 解码器通过 User API 控制机器人的研究示例。

## 集成前的共同要求

- 先完成机器人校准和空载验证；
- 第三方设备只能发送高层任务 / 虚拟外设命令，不直接写关节力矩；
- 必须有独立的硬件急停和受过训练的人员在场；
- 记录设备版本、协议版本、时间戳和异常事件；
- 用于患者前，按机构要求完成风险评估、伦理审批和知情同意。

> ⚠️ 本栏目中的示例默认是**研究 / 工程验证**。若要作为临床产品的一部分，需要单独的法规、网络安全和临床验证工作。
